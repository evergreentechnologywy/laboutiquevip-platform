# Backend Foundation (Phase 0)

This folder introduces a backend-capable foundation without replacing the existing frontend runtime.

## Layout
- `src/`: API skeleton, middleware, and utilities.
- `prisma/`: schema and migration scaffolding.

## Current Endpoints
- `GET /api/health`

## Notes
- RBAC and audit logger are intentionally minimal stubs for Phase 0.
- Prisma migration files are scaffolded to establish required domain tables.
